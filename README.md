# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to quickly create, organize, search, and delete notes. Notes can be categorized as Personal, Work, or Study, and they are saved in the browser so they remain available after refreshing the page.

## Features

* Add notes with a maximum length of 200 characters
* Organize notes into Personal, Work, and Study categories
* Display the date and time each note was created
* Delete individual notes
* Search notes instantly
* Save notes using browser localStorage
* Display the total number of notes
* Responsive layout for mobile devices
* Form validation with clear error messages

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Brian-Ndolo/quicknotes-app.git
   ```

2. Open the project folder:

   ```bash
   cd quicknotes-app
   ```

3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code to run the application locally.
